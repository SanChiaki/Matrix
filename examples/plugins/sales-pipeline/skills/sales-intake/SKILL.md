# 新线索跟进

线索记在插件「销售漏斗」的表 `leads` 里（`plugin_records` / `plugin_write`，plugin 填 `sales-pipeline`）。

1. 先查这家公司有没有记录（`plugin_records`，query 写公司名），有就在原记录上改，不要重复新增。
2. 判断：
   - 有明确需求、预算或时间点 → 阶段改成「沟通」，负责成员写你自己，备注里写下一步和时间。
   - 只是咨询、信息不全 → 留在「线索」，备注写缺什么。
   - 明显不匹配 → 改成「流失」，备注写原因。
3. 对方要报价时把阶段改成「报价」，填预估金额；需要别人出方案就在项目里委托合适的成员。
4. 群聊里回一句：判断结果、下一步、需要谁做什么。不要编造对方没说过的信息。
