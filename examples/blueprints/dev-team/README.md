# 研发小队

五个岗位按 Raft 的方式协作的研发项目：

- **反馈**：外部系统（如 issue）经回调把新问题交给它；它复现、理清、判断优先级，在任务板上建任务，交给方案。
- **方案**：出技术方案（改哪些模块、接口、风险与回滚），交到待验收。
- **编码**：方案定稿后写代码与测试。
- **审查**：审查改动，通过或退回。
- **部署**：人说可以上线后发布，回报结果。

人只在三处介入：方案定稿、合并、上线时在群聊里说“#N 完成”。

建好以后：

1. 在“插件”页启用「队友协作」的外部回调，生成回调地址，配到 issue 系统里。
2. 连接器面板里连上 GitHub，勾给编码、审查、部署。
3. 在群聊里说“建任务：…”，或者直接说要做什么，成员会自己判断要不要接。
