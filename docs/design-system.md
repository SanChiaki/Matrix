# 设计语言

Matrix 所有界面（主界面、管理后台、介绍页、插件页面）共用一套设计语言。这份文档讲规则；变量在
[`matrix/static/tokens.css`](../matrix/static/tokens.css)，部件在 [`matrix/static/style.css`](../matrix/static/style.css)，
两者摆在一起的样式指南页是 `/static/ui.html`（深浅两种主题都要看）。`tests/test_design.py` 检查迁移过的文件只用变量。

## 一、原则

1. **安静的底，清楚的人和 Agent。** 界面大部分是中性色；颜色留给有含义的地方。最重要的一对含义是**谁**：
   靛蓝是 Agent（也是主操作），琥珀是人（也是“等人处理”）。网络图、头像、群聊、看板用的是同一对颜色。
2. **颜色只表达一件事。** 绿 = 完成，红 = 失败或危险，青 = 这块内容来自插件，金 = 对外页面。不拿语义色做装饰；
   同一种状态在所有页面用同一种颜色。
3. **层级靠面，不靠阴影。** 底色 `--bg` → 面 `--surface` → 抬高的面 `--surface-2/3`，加一像素细边框。
   阴影只给真正浮在上面的东西（弹窗、菜单）。
4. **刻度有限。** 字号七级、间距 4px 一档、圆角五档。刻度外的数值要有理由，写在旁边的注释里。
5. **一个区域一个主按钮。** 其余是描边按钮；危险操作用红字按钮。弹窗底栏里主按钮在最右，次要按钮在它左边，
   危险操作在最左、离主按钮最远（`.side .actions` 自动排好，DOM 里照常主按钮在前）。
6. **话说清楚，不说两遍。** 标题下的说明不超过两行（约 90 字），讲这一页能做什么；更细的放到用到它的地方（提示、空状态）。
7. **小字也看得清。** 文字色在各层面上、语义色在各层面和状态药丸的浅色底上都不低于 4.5:1（WCAG AA）。

## 二、变量

| 类别 | 变量 | 说明 |
| --- | --- | --- |
| 中性色 | `--bg` `--surface` `--surface-2` `--surface-3` `--border` `--border-strong` `--text` `--text-2` `--muted` | 三层面 + 三级文字 |
| 强调 | `--accent` `--accent-hover` `--accent-soft` `--accent-line` `--on-accent` | 主操作、选中、焦点 |
| 语义 | `--agent` `--human` `--on-human` `--running` `--completed` `--rejected` `--plugin*` `--release*` `--peer` | 见原则 2；`--peer` 是别人的信任域（介绍页的图） |
| 其他颜色 | `--project-1` … `--project-6`、`--chart-ok/fail`、`--file-*`、`--edge*` `--node-*` `--ring` `--select` `--grid-dot` `--glass`、`--on-color`、`--scrim*` | 项目识别色、图表、文件图标、网络图、遮罩 |
| 字体 | `--font-sans` `--font-mono` | Inter + 苹方；等宽只用于代码、模型名、路径 |
| 字号 | `--fs-xs` 11 · `--fs-sm` 12 · `--fs-md` 13 · `--fs-base` 14 · `--fs-lg` 16 · `--fs-xl` 20 · `--fs-2xl` 28 | 界面正文 13，长文 14，页面标题 20 |
| 行高 | `--lh-tight` 1.3 · `--lh` 1.5 · `--lh-loose` 1.7 | |
| 间距 | `--sp-1` 4 · `--sp-2` 8 · `--sp-3` 12 · `--sp-4` 16 · `--sp-5` 20 · `--sp-6` 24 · `--sp-8` 32 · `--sp-10` 40 · `--sp-12` 48 | 样式表里可以直接写数值，但只能是 0、1、2、4、6、8、12、16、20、24、32、40、48、56、64（1、2、6 留给细线和紧凑处） |
| 版心 | `--page-max` 1280 · `--gutter` | 内容区左右内边距写 `var(--gutter)`：窗口宽于 1280+64 时内容居中、最宽 1280，窄时退回 32 |
| 侧栏 | `--rail-w` 224 | 左侧栏宽度，可拖动（200–420），拖过后写在 body 上 |
| 圆角 | `--radius-xs` 4（标签）· `--radius-sm` 7（控件）· `--radius` 10（卡片）· `--radius-lg` 14（弹窗、大容器）· `--radius-pill` | |
| 阴影 | `--shadow` `--shadow-pop` | 只给浮层 |
| 动效 | `--dur-fast` `--dur` `--ease` | 系统设了“减少动态效果”时为 0 |

主题：默认深色，`<html data-theme="light">` 是浅色（插件页面里 `<html class="light">` 也认）。新增颜色变量要同时给浅色值；
两种主题通用的（项目识别色、文件图标、遮罩）列在 `tests/test_design.py` 的 `shared` 里。介绍页只有深色。

SVG 的 `fill` / `stroke` 属性里写 `var()` 不生效，要写进 `style`（`style="fill: var(--accent)"`）；画布（canvas）用不了变量，开场用 `getComputedStyle` 读一次。

## 三、部件

样式指南页 `/static/ui.html` 是部件的清单：按钮（主、描边 `.ghost`、危险 `.danger`、链接 `.link`）、表单（`.field`、`.hint`、
`.seg`、`.switch`、`.error`、`.warn-box`）、状态药丸 `.pill.status.<状态>`、属性标签 `.tag`、卡片 `.cards > li > .card`、
空状态 `.empty`、页内标签 `.page-tabs`。新页面先从这里挑；需要新部件时先加进 `style.css` 和这一页，再在页面里用。

### 控件

输入框、下拉框 36 高，按钮 32 高，里面的字都是 13（`--fs-md`）；放在同一行时按钮被拉成同高。下拉框不用浏览器自带的箭头，
右边是和图标同粗细的 V 形，颜色跟主题走；悬停时边框变亮、下拉框底色抬一级。链接平时不带下划线，悬停才有（正文 Markdown 里的链接是细底线）。

### 页头

所有页面的页头是同一个结构：**标题一行**（列表页是 `<h1>`，详情页是路径 `项目 / 白板定价`，最后一段就是标题，同一个字号），
**主按钮或操作在标题右边**，**一两句说明在标题下面**，**筛选条件在说明下面单独一行**（如看板的项目、Agent 下拉框）。
页内切换用下划线标签（项目页的 `.page-tabs`、管理后台顶栏的 `.admin-tabs` 是同一种）。管理后台没有侧栏，内容区居中限宽，这是有意的。

### 桌面分辨率

重点看 **1920×1080** 和 **1280×720**（可用高度约 600–720）。宽屏上所有页面（列表、详情、项目对话的消息与输入框、管理后台）
用同一个版心，左右边缘对齐，不把表格和表单拉满；矮屏（高度 ≤ 800）收紧页面上下留白、输入框两行，让消息列表多出一屏的空间。
改布局后在这两种尺寸下各截一张图看。

### 项目页

一个项目只有一页：页头（路径即标题、“项目配置”），下面一排下划线标签，第一个是**对话**（默认）。
对话标签里是项目的群聊和自己的项目会话：上面一行用药丸切换（比页面标签低一级），右边是当前对话的状态和操作；
页面不整体滚动，消息列表自己滚、输入框贴底。私聊和助理不属于任何项目，在单独的对话视图里。

### 状态的颜色

进行中 = 靛蓝，待验收 / 等人处理 = 琥珀，已完成 = 绿，失败 = 红，**已取消 = 中性灰**（取消不是出错）。看板列标题与状态药丸用同一套。

### 卡片

卡片（`.cards > li > .card`）只有一种结构：**头**（头像 + 名字 + 状态或可见范围）、**一两行描述**、**属性标签**（权限、成员名，中性色），
**底栏**左边写事实（几名成员、在哪里跑、是谁的），右边放一个操作（如“对话”，描边按钮）。项目在卡片和页头里用同一个带颜色的“#”头像（侧栏里不带，见下一节）。
底栏有没有按钮都一样高。

### 侧栏

侧栏默认 224 宽，拖右边缘可以在 200–420 之间调（聚焦后左右键也行，双击恢复），宽度记在本机；窄屏下侧栏变成顶栏，不能拖。
对话列表每项只占一行：名字加状态点（运行中、待审核），不显示最后一条消息；项目和项目会话**不带头像**，项目会话缩进挂在项目下面；
私聊仍带 Agent 头像，用来认人。名字太长截断，悬停看全名。

### 侧栏底部

上面一行是运行状态（左）和运行时（右，小字）；下面是账号按钮（头像 + 邮箱），点开是账号菜单：管理后台、深浅色、退出。
账号菜单和“更多”用同一个弹出菜单的写法（`setupPopover`：点外面、Esc、焦点离开就关，上下键移动）。

### 弹窗

弹窗（`.side`）分三段：标题与一行说明、内容、底栏。表单最后一行 `.actions` 就是底栏：贴在弹窗底部，长表单滚动时也看得到。
勾选列表（`.checks`）的标题是框里的表头，不压在边框上。卡片网格里的空状态（`.cards > .empty`）占满一行。

状态药丸与属性标签不混用：**状态**（进行中、待验收、已完成……）用圆角药丸，带圆点；**属性**（权限、模型名、已授权……）用小方角标签。

## 四、插件页面

插件页面在沙箱里，拿不到主界面的样式表，但可以引用同一份变量：

```html
<link rel="stylesheet" href="../_matrix/tokens.css">
```

深浅色不用插件自己处理：调过 `matrix.context()` 后，SDK 按看的人的主题给 `<html>` 加或去掉 `class="light"`；
看的人切换深浅色时，父页面给插件框发 `theme` 事件，SDK 跟着换。插件的主色用 `--accent`，不要另起一个；
沙箱框上沿的青色条是网络加的，表示“这是插件的内容”，插件自己不用再标。四个示例插件都是这样写的。

## 六、改界面时

1. 颜色、字号、圆角只用 `tokens.css` 里的变量，间距落在刻度上；没有合适的，先在 `tokens.css` 和本文第二节加，再用。
2. 改了变量或通用部件，打开 `/static/ui.html` 在深浅两种主题下看一眼。
3. `tests/test_design.py` 自动覆盖主界面与示例插件的全部样式表、页面与脚本：不写死颜色，字号与圆角用变量，间距在刻度上，
   用到的变量都有定义，文字对比度达标，页头说明不超过两行。
