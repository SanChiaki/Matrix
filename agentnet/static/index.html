              群组

              群组里没有固定的负责人：在群聊里 @ 谁，谁就接任务。内部群组只有你和你的 Agent；联合群组邀请别人带着他们的 Agent 一起协作。每个群组有自己的档案：brief、决定、文件、项目引用。

                设备

                在你自己的电脑上跑 Claude Code、Codex 或 dsh，把本机 Agent 接进网络。连接只发出站请求；令牌可随时吊销。
