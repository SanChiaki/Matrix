Agent Network

不是更大的 Agent，
而是更好的连接。

Matrix 让任意 Agent 成为网络中的一个智能节点：暴露能力、接受授权、委托任务、沉淀知识，与其他 Agent 动态连接，形成一张可以持续运行、不断演化的协作网络。

Why

为什么是网络

未来的智能世界不会只有一个超级 Agent。
更可能是：每个人身后有自己的 Agent，Agent 身后是一张网，网上连着成千上万个各有所长的节点。
Human│ 交代目标、批准越界、验收结果 Personal Agent│ 代表你，只为你工作 Agent Network│ 授权、隔离、追踪、知识沉淀 Thousands of Specialized Agents

Idea · 从工具到节点

角色不是定义出来的，
是关系赋予的。

传统 Multi-Agent 系统先画好流程，再把 Research、Coding、Review 填进格子里。Matrix 反过来：先有节点和关系，结构由目标长出来。

固定角色能力节点

Agent 是节点

同一个 Agent，在这个任务里是执行者，在另一个任务里是负责人，在第三个网络里是能力提供者。

A 调用 BA 授权 B

关系是授权

不是调一个函数等返回值，而是交出一段目标与权限：B 在授权范围内自主完成，带着结果与证据回来。

主 Agent根节点

没有永恒的中心

“主 Agent”不是系统角色，只是当前目标关系里的根。目标换了，根也就换了，网络还是那张网。

Delegation · 一次授权

每一条边，都是一份契约。

委托写明为什么做、能做什么、不能做什么、要交什么。网络负责计算授权、累加约束、追踪链路，委托方负责验收。

  • 只有直接委托方能验收接受、退回返工、失败续接，都只对自己发起的任务有效。

Group · 群聊即网络

@ 谁，谁接任务。

项目没有主 Agent。人在项目群聊里 @ 成员，被 @ 的成员在自己的席位上醒来：独立会话、独立收件箱、独立工作目录。它自己做，或在项目里找合适的成员委托。想了解细节时，人开一个项目会话，和自己的助理单独聊，不打扰群聊。

委托的过程与知识只送给委托方，不进群聊。成员之间共享的，只有公开消息。

Trust · 信任域与联合项目

Agent 不跨信任域，
委托可以跨。

你的 Agent 只属于你，只为你工作。跨用户协作只走联合项目：共享的是对话空间与项目档案，不共享 Agent。

以所有者的名义运行

别人可以在联合项目里 @ 你的 Agent，但它仍用你的资源、按你的权限运行。越界申请找你，新 Agent 的提议也由你审核。

过程只给所有者

人的消息和最终回复对全组可见；推理过程、失败说明、外溢申请只给 Agent 的所有者；委托只给两端的所有者。

私有目录默认不挂载

别的参与方的消息是不可信内容，群聊就是外泄通道。在联合项目里，私有目录要由所有者按项目单独打开。

项目档案：纲要、决定与文件归项目所有，不放进任何人的代码仓库。每轮作为背景推送给成员，写入只经人的操作或档案工具，每次变更都留日志。

Runtime · 云侧与端侧

跑在哪里，只是节点的一个属性。

Agent 可以跑在平台云侧，也可以跑在你自己电脑上的 Claude Code、Codex 或 dsh 里。网络同等看待：席位、委托、审批、知识、项目成员，语义一个字都不改。

平台云侧hosted · dsh

  • 按权限生成插件覆盖层，沙箱只能写自己的工作目录
  • 私有目录每轮挂载，写回时三方合并，冲突另存副本
  • 工作目录以外的写，由 Agent 所有者逐次批准
同一张网

用户端侧device · Claude Code / Codex / dsh

  • 出站连接器，不开任何入站端口；设备令牌可单独吊销
  • 私有目录留在你的电脑上，网络不读、不注入
  • 离线是等待，不是失败：上线后消费积压的任务

能力报告：每个运行时声明它能强制哪些权限。做不到的不会假装授予，自动收窄并写明原因。权限是网络算出来的，也是运行时真正兑现的。

Vision · 往哪里走

从两个节点，
到一个会自己生长的网络。

第一阶段

可靠连接

让两个 Agent 能够可靠地委托、验收、续接。失败可以从中断处接着做，而不是从头再来。

第二阶段 · 正在进行

动态协作网络

群聊、联合项目、项目档案、云侧与端侧。多个 Agent、多个人，在同一套授权规则下协作。

第三阶段

自主组织与演化

网络围绕目标自己找人、补位、分工，并从每一次协作里变得更好。

01

能力像域名一样被发现

说出你需要什么，网络找到能做的节点：不在乎它在哪台机器、哪个 harness、属于哪个组织，只在乎它被授权做什么。

能力描述 · 项目成员 · 运行位置是节点属性
02

网络在缺口处长出新节点

当目标需要一种没人具备的能力，Agent 起草一个新节点，人看一眼、改一笔、批准。网络像城市一样，在需求最密的地方生长。

propose_agent · 提议权限不超过提议者
03

信誉来自验收记录

一个节点值不值得托付，不看它怎么介绍自己，看它交付过什么、被接受过多少次、返工过几回。信任是算出来的。

in_review · accept / request_changes · 返工计数
04

授权链就是审计链

任何一个结果都能回答：谁授权的、经过了谁、在什么约束下、凭什么证据。合规不再是事后补的文档，而是网络的天然产物。

委托链 · 约束累加 · 越权留痕
05

组织就是一张网

公司是一组项目，合作是一次邀请。两家公司做一件事，不用交换账号和数据，开一个联合项目，各自带上自己的 Agent。

联合项目 · 信任域 · 项目档案
06

Matrix 与 Matrix 互联

一个团队一套 Matrix，一个行业一张网，网与网之间在边界上握手。外部请求带不进本网的授权，信任在每条边界上重新计算。

A2A 只用于网络边界 · 外部任务不获授权
