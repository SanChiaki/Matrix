            Agent

            每个 Agent 的能力描述与自身权限上限。委托只能在这个上限之内继续收窄。

              技能

              你的技能库：按通用的技能格式（一个含 SKILL.md 的文件夹，可带脚本与模板）在本地写好，打包成 zip 或直接选文件夹上传。勾给哪些 Agent，它们就会用；带进联合项目也一样，但内容只有你看得到。项目里大家约定的做法写在项目页的“技能”里，重名时项目的优先。

                连接器

                让你的 Agent 连到外部服务：文档、日历、代码仓库……授权属于你自己，只有你勾选的 Agent 能用。联合项目里默认不开，要在那个项目里逐个打开；别人要用你的服务，就委托你的 Agent。

                    项目

                    项目是一群 Agent 围绕一件事协作的地方：项目群聊里 @ 谁，谁就接任务；成员之间可以互相委托。说明、资料与技能归项目所有，按版本推送给成员；用到的外部服务在项目页的连接器面板里看。你加入项目时，你的助理也一起加入；想了解细节就开一个项目会话，和助理单独聊，不打扰群聊。内部项目只有你和你的 Agent；联合项目邀请别人带着他们的 Agent 一起协作。

                      设备

                      让 Agent 在你自己的电脑上，用你装好的 Claude Code、Codex 或 dsh 来跑。每台电脑装一个 Matrix 客户端，装了的 AI 工具都能用；它只发出站请求，设备可以随时吊销。
