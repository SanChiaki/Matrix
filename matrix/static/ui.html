Matrix 设计语言

设计语言

颜色、字号、间距都来自 tokens.css，部件来自 style.css。页面和插件只用这里有的东西；这里没有的，先补进来再用。

中性色

三层面：底色、面、抬高的面。层级靠面的明暗和细边框区分，不靠阴影。

语义色

颜色只表达一件事。靛蓝是主操作和 Agent，琥珀是人和“等人处理”，绿是完成，红是失败或危险。

字号

只有七级。界面正文 13px，长文 14px；页面标题 20px。

间距与圆角

间距按 4px 递增；圆角按层级：标签最小，控件次之，卡片、弹窗依次变大。

按钮

一个区域只有一个主按钮。其余用描边按钮；删除这类危险操作用红字按钮，放在最右边。

表单

成员在群聊里 @ 的就是这个名字。

可见范围

名称不能为空。

这个连接器在共享项目里用到时，会先问授权人。

状态与标签

状态用圆角药丸（带圆点），属性用小方角标签。两者不混用。
