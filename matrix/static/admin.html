模型

平台云侧的 Agent 能用哪些模型。用户创建或编辑云侧 Agent 时只能从这里选；端侧 Agent 用自己电脑上 AI 工具的模型，不受影响。

供应商

平台自己接的模型服务（OpenAI / Anthropic 兼容）。密钥加密存在 Matrix，每轮只交给那一个 dsh 进程，Agent 的命令看不到；dsh 里已配置的供应商不用加在这里。

部署方目录

所有项目的主持人都能从这里安装。装进项目的是当时那一版的拷贝：这里更新后，主持人在插件卡上看到“升级”。

上架申请

任何人都可以把插件包交给你审核。看过文件和体检结果后批准，它就进部署方目录；拒绝时写下理由，提交的人看得到。
